# Portfólio do Hak

Site de portfólio de um desenvolvedor independente de jogos. Reúne apresentação pessoal, projetos, participação em Game Jams, ferramentas, habilidades e formas de contato em uma única página com navegação por rolagem.

## Tecnologias

- Next.js com App Router e TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Executar localmente

Instale as dependências e inicie o servidor de desenvolvimento:

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Imagens

As imagens do site ficam em `public/images`. O banner principal usa `welcome-background.gif`; as demais artes e logos também são carregadas dessa pasta.

## Comandos

- `npm run dev`: inicia o ambiente de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm run start`: inicia a versão de produção.
- `npm run lint`: verifica o código com ESLint.
